Accessibility statement · version 0.3.0 candidate content

Accessibility

This static discovery site contains version 0.3.0 candidate content targeting WCAG 2.2 AA. The bytes do not assert the current G6 or G9 state; version-scoped, digest-bound evidence records that state and any release authority. No independent human accessibility audit or representative assistive-technology test is claimed, so the site does not claim conformance.

What should work

  • Navigate and operate search, filters and result links using a keyboard.
  • Use landmarks, headings, labels and a live result-count announcement.
  • Zoom and reflow content without a two-dimensional layout at narrow widths.
  • Use the complete JSON or CSV metadata without the interactive interface.
  • Reduce motion through operating-system preferences.

Known limits

The candidate journeys have not been executed by representative users or with a representative set of assistive technologies. Linked external services have their own accessibility statements and are outside this site’s control. Source-native Welsh-language availability is recorded only where the source metadata makes it explicit.

Technical approach

The site uses semantic HTML, visible focus, no injected HTML, no third-party scripts, no tracking and a restrictive content security policy. JavaScript enhances a complete downloadable metadata catalogue; it does not call HM Land Registry services.

Report a problem

Open an accessibility issue in the source repository with the page, task, browser and assistive technology involved. Do not include property, title, account or other personal information.

Read the map correctly

Discovery metadata, with the sharp edges visible

01

England and Wales by default

HMLR’s normal remit is England and Wales. A source-specific record, such as the UK House Price Index, can have wider coverage.

02

Indicative is not exact

Title plans and polygon products normally show general or indicative boundaries—not a definitive legal boundary.

03

Public is not automatically open

Fees, accounts, bespoke licences and third-party rights remain record-level facts. Check the live source before reuse.

Evidence before interface

A two-stage, fail-closed build

  1. Discover and lock Map source families, authority, rights and risks in a reviewed domain profile.
  2. Freeze public metadata Acquire bounded source envelopes separately; never authenticate or take production data.
  3. Build offline Generate OKF, catalogue and site bytes deterministically, then bind them with checksums.
  4. Evaluate before release Test retrieval, provenance, safety and accessibility; require independent review for approval.
